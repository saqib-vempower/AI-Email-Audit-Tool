# **App Name**: EduMail QA

## Core Features:

- Automated Quality Evaluation: Uses AI as a tool to score advisor emails across grammar, tone, accuracy, empathy, and compliance metrics based on custom school guidelines.
- Leader Dashboard: Visual representation of aggregate team performance and compliance trends over time.
- Per-Advisor Scorecards: Detailed reporting view for individual education advisors to review their performance and feedback loops.
- Advisor Portal: Dedicated interface for education advisors to sign in and review their evaluated email threads.
- Email Analysis Sandbox: A workspace where team leads can paste email text for instant evaluation and real-time feedback generation.

## Style Guidelines:

- Primary color: Deep Midnight (#101E36), a trust-building, professional navy for major layout containers and high-priority text.
- Background color: Sky Mist (#F5F7FA), a cool, light grey-blue that provides a crisp environment for readability and focus.
- Accent color: Seafoam Cyan (#32ADBF), used sparingly for data highlights, toggle states, and interactive feedback icons.
- Primary font: 'Inter', a modern, machined sans-serif that conveys objectivity and professionalism, used for both headlines and data-dense body text.
- Two-pane structural approach: a persistent navy-blue navigation and identity sidebar contrasted with a bright, minimalist content card layout for evaluation data.
- Thin-line, modern icons for metrics such as 'Empathy' (heart icon) or 'Accuracy' (check-circle icon) to aid visual categorization.
- Progressive loading sequences for dashboard charts and a subtle sliding transition when switching between advisor reports.
